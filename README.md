# Super Search

Super Search adds a web search box to your WordPress site. Visitors can enter a search term, choose Google or Bing, and open the results in a new tab without leaving your site.

## Installation

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate **Super Search** from the WordPress Plugins screen.
3. Add the `[super_search]` shortcode to a page, post, or shortcode-enabled widget.

The search field is required, and Google is selected by default.
